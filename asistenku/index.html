Pengaturan API Key Gemini

Kunci Anda sendiri, tersimpan hanya di perangkat ini. Maksimal 10 kunci cadangan.

💡 Mendapatkan API Key Gemini (gratis dari Google):

  1. Buka Google AI Studio dan masuk dengan akun Google Anda.
  2. Klik "Create API Key", lalu salin kodenya (diawali AIza... atau AQ...).
  3. Tempel di kotak di bawah, klik Cek untuk memastikan valid, lalu + Tambah.
  4. Ulangi dengan akun Google lain bila ingin cadangan — kuota gratis dihitung per akun.

Catatan: kunci baru (awalan AQ.) kadang butuh 1–5 menit sebelum aktif. Bila muncul error ACCESS_TOKEN_TYPE_UNSUPPORTED terus-menerus, itu gangguan sisi Google pada sebagian kunci AQ. — solusinya buat kunci di dalam proyek baru di AI Studio, atau buat API key lewat console.cloud.google.com dan batasi ke Generative Language API.

Kenapa pakai kunci sendiri? Karena gratis dan kuotanya milik Anda penuh. AsistenKu tidak menyediakan kunci bersama dan tidak memungut biaya apa pun.
